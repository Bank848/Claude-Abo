# Memory examples

These notes show the format and the kind of habit worth saving. **Every example is invented from a short lesson outline. None is copied from, or edited from, anyone's real memory.** Project names such as `acme-shop` are made up.

Format of one note: a front matter block (`name`, `description`, `metadata.type`, `rewritten: true`) and a body with the rule, a **Why:** line and a **How to apply:** line.

| File | Topic |
|---|---|
| `one-fact-per-file.md` | memory habits |
| `standing-secret-file.md` | memory habits and secrets |
| `route-model-by-difficulty.md` | model routing |
| `confirmed-commands-ask-not-deny.md` | hooks and safety |
| `force-with-lease-explicit-sha.md` | hooks and safety |
| `search-memory-before-giving-up.md` | skill and memory use |
| `guardrail-beside-the-rule.md` | skill and memory use |
| `check-before-reporting-a-blocker.md` | skill and memory use |

To use them, copy a file into the auto-memory folder of one of your projects (`~/.claude/projects/<project>/memory/`) and rewrite it with your own facts. Add one line per note to your `MEMORY.md` index.
