# Lessons

Five short lessons (10 to 15 minutes each) built from the files in this repo.

| # | Lesson | Topic |
|---|---|---|
| 1 | `01-memory.md` | memory notes that stay useful |
| 2 | `02-model-routing.md` | pick the cheapest model that can do the job |
| 3 | `03-hooks-and-safety.md` | hooks, draft-first PRs, a clean public repo |
| 4 | `04-skills-and-context.md` | what your skills cost in context |
| 5 | `05-plan-and-review.md` | plan, review, then build |

**In Claude Code:** open this repo and type `/learn`, or `/learn 01-memory` to start at one lesson. Progress is kept in `.claude-learn-journal.md` (gitignored).

**Format:** each file has front matter (`id`, `title`, `order`, `minutes`, `uses`) and four sections: Why, How the owner does it, Try it, Check. The `uses` list names repo files the lesson refers to; a test checks that every one exists.

Examples come only from `examples/memory/` and shipped files. Nothing here is copied from private notes.
